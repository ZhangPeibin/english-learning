# Formal Curriculum Index

This directory is reserved for authored, sequenced courses. Examples include a
specific American high school English programme or a structured IELTS course.
Adaptive reading passages are generated by the Agent and do not belong here.

No formal course has been published yet.

When a formal course is added, index each lesson with:

- a stable lesson ID;
- course and lesson title;
- CEFR level;
- skills and prerequisites;
- a relative link to the lesson file.

Do not describe IELTS, TOEFL, American high school, business English, or any
other formal course as available until its lessons are listed here.
