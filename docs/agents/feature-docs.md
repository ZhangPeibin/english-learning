# Feature Docs

Pre-PRD discussions live at:

`docs/feature/<release>/<feature-slug>/discussion.md`

Formal PRDs and implementation tickets live in GitHub Issues.

`requirements-analysis` creates or resumes the discussion file. The user chooses the release. Preserve earlier decisions, use a structured decision record, and mark it `ready-for-prd` only after explicit confirmation. Do not create `prd.md`; `to-spec` publishes the PRD to GitHub Issues.
